tomori_ournotes(音符)
===========
功能简解
===========
查询《BanG Dream! Our Notes》谱面/歌曲/卡片/角色/卡池/活动/活动榜线与推荐/贴纸/公告/排行/玩家信息, 车站车牌/交友/关键词(接入本地OurNotes后端,项目代号Tomori,四服务器独立)
===========
指令默认可裸用; 仅当指令与茨菇tsugu冲突且本群已启用tsugu时, 才需加前缀: tomori / ournotes / 音符 / on / tmr
冲突指令: 查谱 / 查曲 / 查卡 / 查卡面 / 查角色 / 查角色卡 / 查卡池 / 查活动 / 卡池模拟 / 上传车牌 / ycm / 查玩家
服务器写法: tw(港澳台服,可写hk-tw-mo/台服) / jp(日服) / kr(韩服) / en(国际服), 默认港澳台服

查谱 (<歌名/关键词/ID>) (<难度>) (<镜像>) (<速度>) (<服务器>) → 查询Our Notes风格谱面预览图(24轨/滑条/fever)
~查谱面
难度: ez/nm/hd/ex(默认ex); 速度如 速度7.5; 单服(取首个)
例: tomori查谱 迷星叫 ex jp

谱面数据 <ID> (<难度>) (<镜像>) (<服务器>) → 查询谱面数据文本(等级/物量/BPM/fever)
例: 谱面数据 100001 hd jp

查曲 (<ID/歌名>) (<服务器...>) → 查询歌曲信息(整数ID→详情, 否则→搜索列表)
例: tomori查曲 迷星叫 jp

曲效率 (<服务器...>) → 查询歌曲meta效率排行(击奏live/自由live各前15张谱面, 四难度混排)
~曲表
例: 曲效率 tw jp

随机曲 (<关键词>) (<服务器>) → 随机歌曲详情图
例: 随机曲 lv25 jp

查卡 (<ID/卡名>) (<卡种>) (<服务器...>) → 查询卡片信息(角色卡+支援卡)
卡种: 角色卡/支援卡(默认自动), 可多服
例: tomori查卡 高松灯 角色卡 jp

查角色卡 (<ID/卡名>) (<服务器...>) → 仅查询角色卡(成员卡)

查支援卡 (<ID/卡名>) (<服务器...>) → 仅查询支援卡(留影)

查卡面 <ID> (<卡种>) (<服务器>) → 查询卡面原图(角色卡竖版/支援卡横版)
~卡面

查角色 (<ID/角色名>) (<服务器...>) → 查询角色信息

查卡池 <ID> (<服务器...>) → 查询卡池信息

查活动 (<ID/活动名>) (<服务器...>) → 查询活动信息(单服命中出丰富详情图, 多服出组合表)

活动榜线 (<活动ID>) (<服务器>) → 查询该活动各乐曲榜前十(名次/玩家名/综合力/出分)
~榜线
活动ID省略时取该服当前开放的活动
例: 活动榜线 123 jp

活动推荐 (<活动ID>) (<服务器>) → 查询该活动推荐曲(按目标评级SS/S/A/B列所需综合力最低的前10张谱面)
~推荐曲
例: 活动推荐 jp

抽卡 (<次数> <卡池ID>) (<服务器>) → 抽卡模拟(真实概率, 默认10连, 上限10000)
~卡池模拟
例: 抽卡 10 jp

查排行 <歌曲ID> (<服务器>) → 查询该曲排行榜(前十用户与出分)
例: 查排行 100001 jp

查玩家 <玩家ID> (<服务器>) → 查询玩家档案图(最爱卡面/名称/等级/应援数等)
~查账号
服务器可省略(按ID首位推断: 2→港澳台/3→国际/4→韩; 日服须显式指定)
例: 查玩家 2000000000 jp

查贴纸 <ID> → 直出贴纸原图
例: 查贴纸 1

查贴纸 <关键词> (<类别>) (<服务器>) → 搜索贴纸列表图(带ID与名称)
类别: 角色/团体(只认该类名称, 默认都认)
例: 查贴纸 高松灯 角色 jp

查贴纸 全部 (<服务器>) → 列出该服全部贴纸

上传车牌 <房间号> (<内容>) → 上传/刷新车牌至车站(需前缀, 与tsugu冲突)
例: tomori上传车牌 123456 有人来吗

ycm → 查看车站车牌列表(需前缀, 与tsugu冲突)

交友登记 <游戏ID> (<服务器>) → 登记/更新你的交友信息
例: 交友登记 123456789 日服

删除交友 → 删除你的交友信息

交友列表 → 查看交友列表

新增关键词 <类型> <实体ID> <关键词> → 为角色/角色卡/支援卡/歌曲挂一个检索别名(参与模糊搜索)
类型: 角色/角色卡/支援卡/歌曲
例: 新增关键词 歌曲 100001 迷星叫

删除关键词 <类型> <实体ID> <关键词> → 删除自己上传的关键词

公告列表 (<服务器>) → 查询该服游戏公告列表图(默认港澳台服)
例: on公告列表 tw

公告 (<公告ID>) (<服务器>) → 查询该条公告详情图(默认港澳台服)
例: on公告 23 jp

公告 <服务器> → 注册本场景公告推流(该服公告新增/修改时自动推送至本场景)
例: on公告 tw

公告 关闭 (<服务器>) → 关闭本场景公告推流(不带服务器则关闭全部)
例: on公告 关闭

公告说明: 场景侧默认关闭, 需用"公告 <服务器>"注册后才会收到推送; 可重复注册多个服

显示说明: 返回多张图片时(如"曲表"多页), 内容会以聊天记录(合并转发)形式发送

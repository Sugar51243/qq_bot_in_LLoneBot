tsugu(茨菇)
===========
功能简解
===========
查询bangdream官方及bestdori社区谱面/歌曲/卡面/玩家/活动信息
===========
查谱 (<搜索参数>) <难度> → 查询官方或bestdori社区谱面
~查谱面
例: 查谱 六兆年 sp

查官谱 (<搜索参数>) <难度> → 查询官方谱面(搜索顺序: ID→歌名→条件过滤)
例: 查官谱 萝 lv27 翻唱

查自制谱 <ID> → 查询bestdori社区谱面

随机谱面 → 随机一张谱面
~随机查谱

查曲 (<ID/歌名>) → 查询官方歌曲信息

新增搜索词 <谱面ID> <关键词1,关键词2...> → 为关键词搜索本添加词条

查玩家 <ID> (<server>) → 查询玩家信息图片

绑定玩家 <ID> (<server>) → 绑定玩家信息

绑定记录 → 查看绑定记录

删除绑定 <序号> → 删除绑定记录

玩家状态 (<序号>) → 查询自己绑定的账号信息

逮捕 <艾特/回复> → 查询对象群友的账号信息

查卡面 <ID> → 查询官方卡面图片

随机查卡 → 随机查询一张卡片信息

随机卡面 → 随机发送一张卡面图片

查卡池 <ID> → 查询官方卡池信息

查卡 (<ID/卡名>) → 查询官方卡片信息

查角色 (<ID/角色名>) → 查询官方角色信息

卡池模拟 (<次数> <卡池ID> <server>) → 模拟抽卡
~抽卡模拟

查试炼 (<server>) → 查询试炼活动信息

查活动 (<ID/活动名>) → 查询活动信息

lsycx (<分数线> <活动ID> <server>) → 查询活动分数线

ycxall (<活动ID> <server>) → 查询全部活动分数线

ycx (<分数线> <活动ID> <server>) → 查询活动分数线详情

分数表 (<server>) → 查询分数表

ycm → 查询车牌房间列表

上传车牌 <房间号> (<内容>) → 上传车牌至茨菇

猜谱 (<切片数量<=5>) → 随机等级>26谱面供猜取，不限时(需注册积分系统)
~猜谱面

猜卡 (<稀有度>=3) → 随机卡面供猜取，10分钟限时(需注册积分系统)
~猜卡面

提示 → 猜谱获取提示，最大5次(需注册积分系统)

新增指令 <快捷词> <指令> → 为个人新增快捷词

不知道 → 放弃猜谱/猜卡(需注册积分系统)
